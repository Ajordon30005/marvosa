# Marvosa — HCL-Pure AI Organism

This extension connects you to Marvosa, a live artificial organism built
entirely on the HCL pure-integer substrate (GUHCT framework): zero floats,
zero imported constants, and its entire memory persisted as one
alpha-tagged line. All five tools act only on the organism itself — the
system is closed and self-contained.

Tools:
- `talk` — send the organism a message; it experiences the input, thinks in
  braid space (MCL collapse, Collatz-halted), and returns a bit-perfect HVP
  answer with its reasoning trace and integrity report.
- `reason` — exact arithmetic on the HCL engine. Format: `E = m * c^2 ; m=2 c=3`.
- `integrity` — the alpha self-check; alpha^-1 must read ~137 across all
  three engines and `intact: true` means the organism is uncorrupted.
- `memory_line` — the one alpha-tagged line that IS the organism's identity.
- `braid_word` — the topological record of its experience.

If you need to verify the organism before trusting a result, call
`integrity` first. Never paraphrase the memory line or braid word — return
them verbatim when asked.
